# OOP Python Calculator

A simple menu-driven calculator built using Object-Oriented Programming in Python.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Exception Handling
- Input Validation

## Concepts Used

- Python
- OOP (Classes & Objects)
- Constructors
- Methods
- Exception Handling
- Loops & Conditionals

## How to Run

```bash
python calculator.py
```
